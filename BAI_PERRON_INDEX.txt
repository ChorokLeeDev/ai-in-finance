6. TECHNICAL SPECIFICATIONS
===============================================================================

Programming Language: Python 3.10
Required Packages:
  - pandas: Data manipulation (v1.3+)
  - numpy: Numerical arrays (v1.20+)
  - scipy: Linear algebra and statistics (v1.7+)
  - hmmlearn: Hidden Markov Models (v0.2+)
  - urllib, zipfile: Built-in for data download

Key Algorithms:
  - HMM: Baum-Welch algorithm (hmmlearn)
  - Regression: OLS via scipy.linalg.solve
  - Break detection: Grid search over all candidate break points
  - Sup-F: Maximum F-statistic over trimmed range

Numerical Methods:
  - Trimming: h=0.15 means minimum 15% of sample per segment
  - F-statistic: (SSR_full - SSR_break) / (SSR_break / dof)
  - Critical values: Bai-Perron (2003) asymptotic distribution

Reproducibility:
  - Random seed: 28 (fixed in HMM)
  - No stochasticity in break-finding
  - Data always downloaded fresh
  - Results deterministic across runs

7. INTERPRETATION GUIDE
===============================================================================

What the Sup-F Statistics Mean:
  
  Sup-F = 79.89 (Normal regime, 0 vs 1 break):
    - Comparing single-equation model vs. 2-regime model
    - Value of 79.89 far exceeds critical value 11.47
    - Conclusion: Strong evidence HML→SMB relationship changed around June 2000
  
  Sup-F = 197.37 (Full sample, 0 vs 1 break):
    - Even stronger evidence when all regimes included
    - Higher Sup-F due to more volatility in full sample
    - Conclusion: Very strong structural break in full dataset

What the Break Dates Mean:
  
  June 22, 2000:
    - Marks peak of dot-com bubble burst
    - Tech stocks (Nasdaq) decline sharply
    - Shift in small-cap vs. value dynamics
    - Risk appetite changes (flight to quality)
  
  August/September 2008:
    - Financial crisis (Lehman collapse Sept 15)
    - Credit markets freeze, liquidity crisis
    - Correlation structures change dramatically
    - Risk-off environment (deleveraging)

What the Granger Coefficients Mean:
  
  Beta = -0.0536 (HML lag coefficient):
    - Past value premium predicts lower SMB (size premium)
    - Negative relationship: value and size move opposite
    - This coefficient changes before/after breaks
  
  Gamma = 0.0337 (SMB lag coefficient):
    - Size premium shows slight positive autocorrelation
    - Tomorrow's SMB partly determined by today's SMB
    - Momentum in size effect

10. TROUBLESHOOTING
===============================================================================

If you encounter issues:

Issue: Import errors with hmmlearn
  Solution: pip install --break-system-packages hmmlearn

Issue: Data download fails
  Solution: Check internet connection, Kenneth French's site status
  Fallback: Manually download and place CSV files in /tmp/french_data/

Issue: Memory issues with HMM fitting
  Solution: Reduce n_iter parameter or use GPU-accelerated alternatives

Issue: Break point search takes too long
  Solution: Increase trimming parameter h (e.g., h=0.20) for larger segments

Issue: Results differ from expected
  Solution: Check random seed is 28, ensure data period is 1990-2024
