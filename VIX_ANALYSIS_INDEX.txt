================================================================================
ADDRESSING THE REVIEWER'S "CIRCULARITY" CRITIQUE
================================================================================

Reviewer's Concern:
  "Using HMM regime labels derived from the SAME returns (HML, SMB) used in
   Granger tests creates circular reasoning that cannot be eliminated."

This Analysis Addresses It By:
  1. Defining regimes using VIX alone (external to factor returns)
  2. VIX is market-wide volatility indicator, not tied to HML/SMB relationship
  3. Regime thresholds are objective quantiles, not data-mined
  4. Results reproducible with public data
  5. Shows HML→SMB is significant across ALL VIX regimes, suggesting robustness

Expected Response:
  "We conducted an external regime validation using VIX terciles. Results show
   that HML→SMB Granger causality holds across all VIX-defined regimes
   (p<0.05), and exhibits a dramatic structural break around 2008 in the
   Normal regime (pre-2008: p<0.001; post-2008: p=0.71). This robustness to
   external regime definition addresses concerns about circularity in our
   primary HMM-based analysis."

TECHNICAL NOTES
================================================================================

Granger Test Implementation:
  - VAR specification: SMB_t = α₀ + α₁·SMB_{t-1} + β₁·HML_{t-1} + u_t
  - H₀: β₁ = 0 (HML does not Granger-cause SMB)
  - Test: F-test on coefficient restriction
  - Lag order: 1 (matches HMM paper specification)
  - Standard errors: OLS (diagonal matrix, conservative)

VIX Regime Definition:
  - Terciles (33rd and 67th percentiles) chosen for balance across regimes
  - Each regime contains ~33% of observations
  - Alternative splits (quartiles, median, percentiles) can be tested
  - Percentile thresholds: 14.97 (p33), 20.97 (p67)

Data Sources:
  - Fama-French: Ken French Data Library (official source)
  - VIX: Federal Reserve Economic Data (FRED) via pandas_datareader
  - Both sources are publicly available, updated regularly

Reproducibility:
  - All code is open source (Python, pandas, statsmodels)
  - Data sources are public and stable
  - Results are deterministic (no random seeds in main analysis)
  - Any researcher can run vix_instrument.py with same output
