## 🚧 POTENTIAL BLOCKERS

### Technical Blockers

**1. Feature Engineering Complexity**
- **Risk**: Tasks may need complex manual feature engineering
- **Mitigation**: Start with auto-generated features if available
- **Fallback**: Use simpler feature sets, accept moderate performance

**2. Computation Time**
- **Risk**: 50 seeds × 4 tasks = 200 model training runs
- **Mitigation**: Parallelize across tasks
- **Fallback**: Reduce to 25 seeds if time-constrained

**3. Missing Data**
- **Risk**: Tasks may have data quality issues
- **Mitigation**: Check data early (Day 1)
- **Fallback**: Substitute with alternative tasks

### Statistical Blockers

**4. Correlation Weakens**
- **Risk**: Adding new tasks could weaken ρ (e.g., ρ=0.55)
- **Impact**: If ρ drops and p>0.05, hurts paper
- **Mitigation**: Analyze per-domain correlations
- **Fallback**: Report heterogeneous effects, still valuable

**5. Threshold Doesn't Generalize**
- **Risk**: 40% threshold may not work on new tasks
- **Impact**: Framework needs revision
- **Mitigation**: Adjust threshold (e.g., 35% or 45%)
- **Fallback**: Report domain-specific thresholds
