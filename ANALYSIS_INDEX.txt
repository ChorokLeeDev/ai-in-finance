================================================================================
METHODOLOGY DETAILS
================================================================================

1. DATA ACQUISITION
   - Downloaded from: https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/ftp/
   - Files: F-F_Research_Data_5_Factors_2x3_daily_CSV.zip
   - Files: F-F_Momentum_Factor_daily_CSV.zip
   - Period: 1990-01-01 to 2024-12-31
   - Frequency: Daily (business days only)

2. FACTOR EXTRACTION
   - HML (High Minus Low): Value factor
   - SMB (Small Minus Big): Size factor
   - Cleaned NaN values, converted to decimal format

3. TRAIN-TEST SPLIT
   - Training: 1990-2012 (6,001 observations)
   - Test: 2013-2024 (3,131 observations)

4. STUDENT-T HMM IMPLEMENTATION
   - K=3 regimes (Normal, Elevated, Crisis)
   - Random seed: 28 (reproducibility)
   - Training iterations: 150
   - Viterbi algorithm for decoding
   - Forward-backward algorithm for likelihood

5. SCALE CONVENTIONS
   A. Percentage Units (×100):
      - HML and SMB multiplied by 100
      - Values: approximately ±2-3% per day
      - Paper's primary convention
   
   B. Decimal Units (Raw):
      - Returns as downloaded
      - Values: approximately ±0.0002-0.0003
      - Natural data representation

6. STATISTICAL TESTS
   A. Granger Causality (In-Sample, Normal Regime):
      - Direction: HML → SMB
      - Lag order: Automatic (1-5 lags)
      - H0: HML does not Granger-cause SMB
      - Test statistic: F-ratio of restricted vs. unrestricted RSS
   
   B. Structural Break Test (Quandt-Andrews):
      - Tests for regime shift in training period
      - Trim: 15% from each end
      - Statistic: sup-F across all breakpoints
      - Critical value approximation: Andrews (2003)
   
   C. Out-of-Sample Granger (Frozen HMM):
      - HMM parameters fixed after training
      - Applied to 2013-2024 data
      - Per-regime Granger causality tests
      - HAC-robust standard errors (Newey-West)
   
   D. Permutation Test (Elevated Regime OOS):
      - Shuffles x variable 1000 times
      - Recomputes F-statistic under null
      - Calculates empirical p-value

7. COMPARISON METHODOLOGY
   - Ran identical analysis on both scales
   - Compared regime assignments (agreement rate)
   - Compared all statistical test results
   - Identified scale-invariant properties

WHY SCALE-INVARIANCE OCCURS:
  1. Multiplicative scaling: x' = 100*x is linear transformation
  2. Likelihood invariance: Gaussian/Student-t unaffected by proportional scaling
  3. Relative distances: Mahalanobis distance scale-invariant
  4. Granger regression: Coefficients and F-statistics unaffected
  5. P-values: Derived from scale-invariant test statistics
