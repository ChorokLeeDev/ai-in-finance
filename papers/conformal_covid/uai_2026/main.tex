\begin{abstract}
Conformal prediction provides distribution-free coverage guarantees, but these degrade under distribution shift---and practitioners currently lack tools to anticipate \textit{which} deployed models will fail before deployment.
We propose SHAP concentration---the fraction of feature importance concentrated
in the top feature---as a \textbf{pre-deployment diagnostic} for conformal
prediction vulnerability. Using COVID-19 as a case study across 8
supply chain tasks experiencing varying degrees of feature turnover,
we find coverage drops ranging from 0.1\% to 77\% (all paired $p \leq 0.005$, 50
seeds). SHAP concentration, computed \textit{before} observing test data,
correlates with which tasks fail: $\rho = 0.833$, $p = 0.010$ within
supply chain ($n=8$); $\rho = 0.691$, $p = 0.019$ across 3 domains ($n=11$
including clinical trials and motorsport). Binary classification tasks are structurally protected against this failure mode, clarifying the diagnostic's scope to multiclass settings. We provide mechanistic intuition: when a model concentrates importance on a single
out-of-distribution feature, test conformity scores stochastically dominate
calibration scores, breaking the exchangeability assumption. In contrast, post-hoc diagnostics
(prediction entropy, calibration error) can only detect failures
\textit{after} deployment. Quarterly retraining partially mitigates vulnerable task
coverage loss (+19~pp, $p = 0.04$) while robust tasks need no intervention.
Adaptive Conformal Inference recovers coverage for vulnerable tasks but inflates
prediction sets to 30--82\% of classes for those needing intervention (Useful to Vacuous); robust tasks need no ACI. We formalize a decision framework: compute SHAP
concentration pre-deployment; retrain quarterly if vulnerable; skip retraining
if robust.
\end{abstract}

\section{Introduction}\label{sec:intro}

Conformal prediction provides distribution-free coverage guarantees under the assumption of exchangeability~\citep{vovk2005algorithmic}. However, real-world deployments face distribution shifts that violate this assumption. While prior work characterizes \textit{how} conformal prediction degrades under shift~\citep{tibshirani2019conformal, barber2023conformal}, a critical gap remains: \textbf{Can we identify which deployed models will fail before observing test data?}

We propose \textbf{SHAP concentration}---the fraction of total feature importance concentrated in the top feature---as a pre-deployment diagnostic for conformal prediction vulnerability. Using a supply chain benchmark with temporal splits aligned to COVID-19 (February--July 2020), we conduct an observational case study where 8 classification tasks experience identical temporal shift yet exhibit coverage drops ranging from negligible ($<$1\%) to catastrophic ($>$70\%).

Our contributions:

\begin{enumerate}
    \item \textbf{Pre-deployment diagnostic}: SHAP concentration, computed solely on validation data, correlates with catastrophic conformal failure under severe shift. Within supply chain: $\rho = 0.833$, $p = 0.010$ ($n=8$). Across 3 domains (supply chain, clinical trials, motorsport): $\rho = 0.691$, $p = 0.019$ ($n=11$). SHAP concentration achieves stronger correlation than alternative pre-deployment diagnostics---native feature importance ($\rho = 0.667$, $p = 0.071$) and ensemble disagreement ($\rho = 0.452$, $p = 0.260$)---though the difference is not formally testable at $n=8$. Binary APS exhibits a structural ceiling effect; concentration is diagnostic specifically for multiclass settings.

    \item \textbf{Mechanistic intuition}: We provide a heuristic argument that single-feature dependence on an OOD feature causes test conformity scores to stochastically dominate calibration scores, breaking exchangeability (Section~\ref{sec:theory}). We verify this directly: for catastrophic tasks, test conformity scores stochastically dominate calibration scores (KS $= 0.68$--$0.96$, all $p < 10^{-10}$; Figure~\ref{fig:cdfs}).

    \item \textbf{Quantification with statistical rigor}: Coverage drops across 8 tasks range from 0.1\% to 77.1\%, all with paired $p \leq 0.005$ (Wilcoxon, 50 seeds). The correlation magnitude is stable under leave-one-out analysis ($\rho \in [0.75, 0.96]$), though significance is not maintained for 2 of 8 jackknife samples due to reduced power at $n=7$.

    \item \textbf{Actionable framework}: Quarterly retraining partially mitigates vulnerable task coverage loss by +19~pp ($p=0.04$); robust tasks (99.8\% coverage) need no intervention. The framework's concentration threshold is robust across 30--45\% (Recall $= 1.0$; Appendix~\ref{app:threshold}).

    \item \textbf{Binary ceiling effect}: Binary APS prediction sets ($\{0\}, \{1\}$, or $\{0,1\}$) are structurally protected against the coverage degradation that concentration detects. This boundary condition clarifies when the diagnostic applies (multiclass) and when it does not (binary).
\end{enumerate}

\section{Related Work}\label{sec:related}

\textbf{Conformal Prediction.} \citet{vovk2005algorithmic} introduced conformal prediction with exchangeability guarantees. Recent work extends to classification~\citep{romano2020classification} and regression~\citep{romano2019conformalized}. \citet{angelopoulos2021gentle} provide a comprehensive tutorial.

\textbf{Conformal Prediction Under Shift.} \citet{tibshirani2019conformal} study covariate shift with known propensity scores. \citet{podkopaev2021distribution} develop distribution-free prediction sets under label shift. \citet{barber2023conformal} provide a comprehensive treatment beyond exchangeability. These works characterize degradation theoretically; we complement them with an empirical diagnostic that identifies \textit{which} tasks will fail before deployment.

\textbf{Adaptive Methods.} \citet{gibbs2021adaptive} propose Adaptive Conformal Inference (ACI) for non-stationary settings, with extensions by \citet{zaffran2022adaptive} for time series and \citet{feldman2023achieving} for online risk control. \citet{angelopoulos2024conformal} generalize conformal prediction to broader risk measures. Our experiments show ACI recovers marginal coverage under severe shift but at a substantial cost in prediction set informativeness.

\textbf{Shift Detection.} WILDS~\citep{koh2021wilds} and Shifts~\citep{malinin2021shifts} provide benchmarks, while \citet{gulrajani2020search} show robust methods often fail under temporal shift. \citet{garg2022leveraging} use unlabeled test data to predict accuracy degradation---a related goal but requiring test-time observations. Existing shift-detection methods (e.g., prediction entropy, calibration error) are \textit{post-hoc}. Our contribution is a \textit{pre-deployment} diagnostic using feature importance structure, requiring no test data.

\textbf{Interpretability for Reliability.} Our work connects SHAP~\citep{lundberg2017unified} to model reliability assessment, extending the use of feature attribution from debugging~\citep{adebayo2018sanity} to prospective failure diagnosis.

\section{Methodology}\label{sec:method}

\subsection{Dataset and Temporal Splits}

We use the SALT (Supply chain ALlocaTion) dataset from RelBench~\citep{fey2023relbench}, a supply chain benchmark with temporal splits. All 8 classification tasks from the rel-salt benchmark are included; no tasks were excluded.
\begin{itemize}
    \item \textbf{Train}: Before February 2020 (pre-COVID)
    \item \textbf{Validation}: February--July 2020 (COVID onset)
    \item \textbf{Test}: After July 2020 (COVID peak)
\end{itemize}

\noindent\textbf{Data separation protocol.} SHAP concentration and the 40\% threshold are computed exclusively on validation-time data. The test set is used only for final evaluation and never informs diagnostic thresholds. Task-level severity labels (SEV/ROB) used for threshold evaluation are defined by observed test coverage drops; the threshold sensitivity analysis in Appendix~\ref{app:threshold} is therefore post-hoc validation, not prospective assessment.

\subsection{Conformal Prediction Setup}

We use Adaptive Prediction Sets (APS)~\citep{romano2020classification} with $\alpha = 0.1$ (90\% target coverage):
\begin{enumerate}
    \item Train LightGBM classifier with default hyperparameters
    \item Calibrate conformal predictor on 50\% of validation set
    \item Evaluate coverage on held-out validation and test sets
\end{enumerate}

\subsection{Ensemble Protocol}

We train 50 independent models with seeds 42--91. For each seed $s$: train model $M_s$, split validation 50/50 into calibration $\mathcal{D}_{\text{cal}}^s$ and evaluation $\mathcal{D}_{\text{eval}}^s$, calibrate $\text{CP}_s$ on $\mathcal{D}_{\text{cal}}^s$, evaluate on both $\mathcal{D}_{\text{eval}}^s$ and test. We report mean, 95\% confidence intervals ($t$-distribution), and paired Wilcoxon tests (seed-level). This is \textit{not} ensemble prediction---each seed is an independent experimental trial providing paired comparisons.

\subsection{Feature Overlap Metric}

Feature temporal stability uses Jaccard similarity:
\begin{equation}\label{eq:jaccard}
J(f) = \frac{|A_{\text{train}} \cap A_{\text{test}}|}{|A_{\text{train}} \cup A_{\text{test}}|}
\end{equation}
where $A_{\text{train}}$ and $A_{\text{test}}$ are the sets of unique values for feature $f$ in train and test data. In the pre-deployment framework (Section~\ref{sec:framework}), we substitute validation data for test data as a proxy.

\subsection{SHAP Concentration Diagnostic}\label{sec:shap_method}

We define the SHAP concentration metric as:
\begin{equation}\label{eq:concentration}
C = \frac{\phi_1}{\sum_{j=1}^{p} \phi_j}
\end{equation}
where $\phi_j$ is the mean absolute SHAP value of the $j$-th feature computed on validation data using TreeExplainer~\citep{lundberg2020local}, and $\phi_1$ is the importance of the top-ranked feature. $C$ is computed \textbf{before deployment} using only validation data.

\subsection{Why SHAP Concentration?}\label{sec:why_shap}

A natural question is whether simpler diagnostics suffice.

\textbf{Feature overlap (Jaccard) is insufficient.} Tasks relying on transaction IDs have Jaccard $\approx 0$ while tasks with entity-based features have Jaccard $> 0.5$ (Table~\ref{tab:overlap}), yet Jaccard alone cannot explain the full range of coverage drops.

\textbf{Post-hoc metrics require test data.} Prediction entropy changes and Expected Calibration Error (ECE) shifts can detect failures---but only \textit{after} observing test data (Section~\ref{sec:baselines}). SHAP concentration is the only diagnostic available before deployment.

\textbf{Why not raw feature importance?} Raw importance values are not comparable across tasks (different scales, feature counts). Concentration normalizes to a $[0,1]$ scale, enabling cross-task comparison.

\textbf{Why top-1?} We compared top-1 concentration against alternatives: top-2, top-3, Herfindahl-Hirschman Index (HHI), and feature importance entropy. Only top-1 concentration achieves significant correlation with coverage drop ($\rho = 0.833$, $p = 0.010$); all alternatives are non-significant ($p > 0.10$). The discriminating power of top-1 arises because sales-office has high top-2/3 concentration (77--85\%) but near-zero coverage drop---the diagnostic signal is specifically whether a \textit{single} dominant feature drives predictions, not overall feature spread.

\section{Intuition: Why Concentration Correlates with Failure}\label{sec:theory}

We provide intuition for why SHAP concentration correlates with conformal failure under severe feature shift. The following argument is heuristic; formal analysis under explicit distributional assumptions is left for future work.

\textbf{Setup.} Consider a model $f$ trained on features $(x_1, \ldots, x_p)$, calibrated with conformal predictor CP at level $\alpha$. For APS, the conformity score is $s(x,y) = \sum_{j=1}^{k} \hat{f}_{\pi_j}(x)$, where $\pi$ orders classes by decreasing $\hat{f}_j(x)$ and $\pi_k = y$ (i.e., the cumulative probability mass from the most likely class until the true label is included). The conformal guarantee requires that calibration and test scores be exchangeable.

\textbf{Claim (heuristic).} If (i) the model concentrates importance on feature $x_1$ (i.e., $C \gg 0$), and (ii) $x_1$ undergoes complete distribution shift ($J(x_1) \approx 0$), then the conformity scores on the test set stochastically dominate the calibration scores (i.e., test scores are systematically larger), and the coverage guarantee breaks.

\textbf{Argument.} When $C$ is high, the model's predictions are primarily determined by $x_1$. Under complete shift, test-time values of $x_1$ are entirely unseen during training. The model maps these to arbitrary predictions (effectively random with respect to the true label distribution), producing conformity scores $s_{\text{test}}$ that are systematically higher than $s_{\text{cal}}$. Formally:

\begin{equation}\label{eq:stochastic_dom}
P(s_{\text{test}} \leq t) \leq P(s_{\text{cal}} \leq t), \quad \forall t
\end{equation}

This stochastic dominance means the conformal threshold $\hat{q}$ (calibrated to achieve $1-\alpha$ coverage on calibration data) becomes too small for test data, producing prediction sets that systematically exclude the true label.

\textbf{Diversification protects.} When importance is distributed across $p$ features (low $C$), the effect of any single OOD feature is attenuated. Even if all features shift, the model's score distribution depends on a ``portfolio'' of features whose individual effects partially cancel under resampling. This is analogous to portfolio diversification in finance: concentrated bets amplify risk; diversified exposure dampens it.

\textbf{Empirical verification.} Figure~\ref{fig:shap} is consistent with this argument: catastrophic tasks show concentrated importance explosion (4.5$\times$) in the top feature, while robust tasks redistribute importance across features (10--20$\times$ increases distributed). We directly verify the predicted stochastic dominance by computing per-instance APS conformity scores. For the most catastrophic task (sales-shipcond, 71.6\% drop), calibration and test score distributions differ dramatically (KS $= 0.956$, $p < 10^{-10}$): calibration scores spread across $[0.2, 1.0]$ (mean $= 0.54$) while test scores concentrate near $1.0$ (mean $= 0.98$), confirming test scores stochastically dominate calibration scores (Figure~\ref{fig:cdfs}). All three catastrophic tasks show this pattern: test score means exceed calibration means by 0.02--0.44. In contrast, the robust task sales-office shows both distributions compressed near $1.0$ (means $0.996$ vs.\ $1.000$). Full KS statistics for all 8 tasks in Appendix~\ref{app:ks}.

\subsection{SHAP Concentration Correlates with Failure}\label{sec:shap_results}

Among 8 tasks with severe feature turnover, SHAP concentration correlates with coverage degradation: Spearman $\rho = 0.833$, $p = 0.010$ (Table~\ref{tab:stratified_correlation}, Figure~\ref{fig:n11_correlation}). Bootstrap 95\% CI: $[0.29, 1.00]$ (10,000 resamples). The correlation magnitude is stable under leave-one-out analysis ($\rho \in [0.75, 0.96]$), though statistical significance is not maintained for 2 of 8 jackknife samples ($p = 0.052$) due to reduced power at $n=7$. SHAP concentration values are highly stable: bootstrap resampling (1,000 resamples of 10K validation samples) yields coefficient of variation below 1\% for all tasks, with 95\% CIs within $\pm$1 percentage point.

\textbf{Mechanism.} Figure~\ref{fig:shap} reveals the distinction. Catastrophic tasks: the dominant feature experiences a concentrated importance explosion (4.5$\times$ increase). Robust tasks: importance redistributes across features with ranking reshuffle (10--20$\times$ increases distributed). This matches the heuristic prediction in Section~\ref{sec:theory}.

\textbf{False positives.} Two tasks with concentration $>$40\% remain robust: sales-office (secondary feature SALESORG has Jaccard $= 0.61$) and item-shippoint (high model variance). These motivate the protective-factor check in our framework (Section~\ref{sec:framework}).

\textbf{Task independence.} Intraclass correlation analysis confirms task identity explains the majority of seed-level variance in coverage drops (ICC $= 0.675$, 95\% CI $[0.47, 0.90]$; effective $n_{\text{eff}} = 11.7$). Per-task ICC(val,test) is negative for all 8 tasks, indicating paired tests are conservative. Details in Appendix~\ref{app:icc}.

\textbf{Cross-domain extension.} Extending to 11 tasks across 3 domains (supply chain, clinical trials, motorsport; Section~\ref{sec:cross_domain}) yields $\rho=0.691$, $p=0.019$. The attenuation from $0.833$ to $0.691$ is entirely attributable to the binary ceiling effect: binary APS tasks cluster near zero drop regardless of concentration.

This association is observational; prospective validation on held-out domains is needed before the diagnostic can be used for forward-looking prediction.

\subsection{Diagnostic Comparison}\label{sec:baselines}

We compare SHAP concentration against two alternative pre-deployment diagnostics that require no test data (Table~\ref{tab:diagnostic_comparison}).

\textbf{Native feature importance concentration}: top-1 LightGBM gain divided by total gain (zero SHAP cost, single seed). Achieves $\rho = 0.667$ ($p = 0.071$)---directionally correct but not significant at $\alpha = 0.05$. The weaker discrimination arises because native gain conflates feature cardinality with predictive importance: sales-office shows 66.1\% native concentration (vs.\ 42.6\% SHAP) despite near-zero coverage drop.

\textbf{Ensemble disagreement}: standard deviation of validation coverage across 50 seeds (seed 42). Achieves $\rho = 0.452$ ($p = 0.260$). Disagreement captures model instability but not the feature-level mechanism driving conformal failure.

\textbf{Class cardinality as confound.} $\log(\text{num\_classes})$ alone correlates with coverage drop ($\rho = 0.743$, $p = 0.035$). However, partial correlations reveal an asymmetry: concentration retains $\rho_{\text{partial}} = 0.629$ after controlling for $\log(\text{num\_classes})$, while $\log(\text{num\_classes})$ drops to $\rho_{\text{partial}} = 0.334$ after controlling for concentration. Neither achieves significance at $n=8$, but the asymmetry suggests concentration captures information beyond class count.

We additionally compare against two \textit{post-hoc} baselines computed from 10-seed ACI experiments:

\textbf{Prediction entropy change}: $\Delta H = H_{\text{test}} - H_{\text{val}}$, where $H = -\sum_c p_c \log p_c$ averaged over instances.

\textbf{Expected Calibration Error change}: $\Delta \text{ECE} = \text{ECE}_{\text{test}} - \text{ECE}_{\text{val}}$.

Both metrics can detect shift \textit{after} test data is observed, but neither is available at deployment time. SHAP concentration is computed solely on validation data, making it actionable for pre-deployment risk assessment. Comparison across 7 tasks in Appendix~\ref{app:baselines}.

\textbf{Severe tasks}: ACI provides large coverage gains (+48--72pp, all $p < 0.01$) but at varying cost to informativeness (Utility column). For sales-group (462 classes), ACI expands sets to 82\% of all classes---formally ``Vacuous,'' predicting nearly every class is possible. Sales-payterms is ``Marginal'' (40\% of classes). Sales-office is instructive: at 99.9\% standard coverage, ACI slightly \textit{reduces} coverage ($-$1.0pp, n.s.) as the adaptive mechanism overshoots toward the 90\% target. All robust tasks maintain ``Useful'' prediction sets---they already achieve near-target coverage without ACI.

\textbf{Synthesis}: Across all 8 tasks, ACI improves coverage for vulnerable tasks but utility depends on set-size growth; vacuity appears in high-class-cardinality settings (s-group: 462 classes $\rightarrow$ 82\% Vacuous). For robust tasks, ACI is unnecessary or counterproductive.

\textbf{Deployability metric}: We define the \textit{usable-set rate} as $\text{Size}/|\mathcal{Y}|$, the mean prediction set size divided by the number of classes. Values below 40\% indicate actionable predictions (``Useful''); above 60\% indicates near-vacuous output. Of the 3 severe tasks where ACI is needed, only 1 (s-shipcond, 30\%) produces deployable predictions. This reinforces our diagnostic: identify vulnerability \textit{before} deployment rather than relying on ACI to fix it \textit{after}.

To establish that COVID-19 represents a unique shift, we use pre-COVID data: train on 2018, validate on 2019-H1, test on 2019-H2 (Table~\ref{tab:placebo} in Appendix). COVID causes 6--140$\times$ more degradation than normal temporal drift for vulnerable tasks. This confirms that the observed coverage collapse is attributable to COVID-19 disruption rather than routine temporal drift, and that the SHAP concentration diagnostic identifies vulnerability specific to the severe shift regime.

\section{Decision Framework}\label{sec:framework}

The following protocol, empirically motivated by our analysis, guides practitioners deploying conformal prediction in non-stationary settings:

\begin{enumerate}
    \item \textbf{Compute SHAP concentration} $C = \phi_1 / \sum_j \phi_j$ on validation data (Eq.~\ref{eq:concentration})
    \item \textbf{If $C \leq 40\%$}: Task is \textbf{robust} (distributed importance protects against shift)
    \item \textbf{If $C > 40\%$}: Check for protective factors---secondary features with train-validation Jaccard $> 0.5$ \textit{and} importance $> 15\%$ (validation overlap serves as a pre-deployment proxy for deployment-time feature stability)
    \begin{itemize}
        \item Protective factors exist $\rightarrow$ \textbf{robust}
        \item Otherwise $\rightarrow$ \textbf{vulnerable}: implement quarterly retraining
    \end{itemize}
    \item \textbf{For robust tasks}: Skip retraining (saves computational cost)
    \item \textbf{Monitor}: Track empirical coverage as early warning
\end{enumerate}

\noindent\textbf{Threshold selection.} The 40\% threshold is proposed based on the empirical distribution of SHAP concentration values on validation data: a natural gap separates low-concentration tasks (24--29\%) from high-concentration tasks (43--54\%), visible in Table~\ref{tab:framework_validation}. We emphasize that this threshold is \textit{exploratory}, derived from $n=8$ multiclass tasks, and should be validated before deployment in new domains.

\noindent\textbf{Cross-domain transfer test.} Here we define ``at-risk'' as coverage drop ${>}15\%$ (encompassing both SEV and moderate-drop tasks), broadening the detection target beyond the extreme SEV category ($>$50\% drop, Table~\ref{tab:main_results}) to capture any non-trivial failure. Applying the 40\% threshold without re-tuning to the full $n=11$ cross-domain set (Table~\ref{tab:cross}) yields Recall $= 1.0$, F1 $= 0.80$ (or F1 $= 0.67$ under the stricter ${>}50\%$ SEV definition). The binary tasks do not violate the threshold---study-outcome (20.8\%, below threshold) is correctly classified as robust, while driver-dnf (48.1\%, above threshold) is a false positive only because binary APS is structurally protected. The 45\% threshold achieves F1 $= 0.89$ (or $0.75$ under ${>}50\%$) at $n=11$. The sensitivity analysis in Appendix~\ref{app:threshold} reports performance across the 30--50\% range.

\section{Discussion}\label{sec:discussion}

\textbf{Confidently Wrong Models.} Counter-intuitively, catastrophic tasks show \textit{smaller} prediction sets at test time (\eg, sales-shipcond: 7.0 $\rightarrow$ 3.0). The model concentrates probability on a small number of wrong classes rather than spreading uncertainty. This is mechanistically consistent with our theory: when the model depends on a single OOD feature, it maps unseen values to arbitrary but \textit{concentrated} probability distributions. Appendix~\ref{app:baselines} confirms that prediction entropy \textit{decreases} for catastrophic tasks---the opposite of what entropy-based monitoring would flag.

\textbf{High Variance as Warning.} Tasks with CV $> 50\%$ across seeds are in knife-edge regimes. This is itself an early warning that conformal calibration will be unreliable.

\textbf{Alternative Conformal Methods.} Mondrian conformal prediction~\citep{vovk2005algorithmic} calibrates per-class, but when the dominant feature undergoes complete shift (Jaccard $\approx 0$), test-time values have no calibration counterpart. Weighted conformal prediction~\citep{tibshirani2019conformal} faces the same obstacle: likelihood ratio weights require distributional overlap. SHAP concentration describes the \textit{fixed model's} learned dependence structure (computed on validation data), not a property of the test distribution, making it applicable precisely when these methods cannot be.

\textbf{Limitations.}

\textbf{Generalizability.} (1) Cross-domain validation extends to 11 tasks across 3 domains, but the core SALT analysis (8 tasks) shares a single database, temporal split, and model class. The effective independence of SALT observations is limited by shared structure; cross-domain tasks partially mitigate this ($\rho = 0.691$, $p = 0.019$ at $n=11$). (2) The 40\% threshold is exploratory, derived from $n=8$ multiclass tasks. Cross-domain transfer (Recall $=1.0$ at $n=11$) is encouraging but insufficient for deployment recommendations; practitioners should calibrate thresholds on held-out domains. (3) Binary APS tasks exhibit a structural ceiling effect (Section~\ref{sec:cross_domain}) that limits both the failure mode and the diagnostic's applicability; the concentration diagnostic is validated for multiclass settings only.

\textbf{Methodology.} (4) The 50 random seeds share identical training and test data, varying only in model randomness and calibration splits. ICC analysis (Appendix~\ref{app:icc}) confirms task identity explains most variance (ICC $= 0.675$, effective $n_{\text{eff}} = 11.7$), and per-task negative ICC(val,test) indicates paired tests are conservative. After Holm--Bonferroni correction for 5 concentration metrics tested, the primary result reaches $p_{\text{adj}} = 0.050$ (Appendix~\ref{app:icc}). (5) Among pre-deployment diagnostics (Section~\ref{sec:baselines}), SHAP concentration achieves stronger correlation than native feature importance ($\rho = 0.667$, $p = 0.071$) and ensemble disagreement ($\rho = 0.452$, $p = 0.260$), though the difference between dependent correlations is not formally testable at $n=8$.

\textbf{Scope.} (6) The diagnostic is model-specific: RandomForest trained on the same data shows different concentration profiles and the correlation does not replicate ($\rho = 0.30$, $p = 0.47$; Appendix~\ref{app:rf}). This is expected---SHAP concentration measures a model's learned dependence structure, not a data-level property---but means the diagnostic must be computed for the deployed model class. (7) The protective-factor thresholds (Jaccard $> 0.5$, importance $> 15\%$) are preliminary heuristics validated on 1 example. (8) The intuition in Section~\ref{sec:theory} is heuristic; formal analysis under explicit distributional assumptions remains open.

\section{Conclusion}\label{sec:conclusion}

We propose SHAP concentration as a pre-deployment diagnostic for conformal prediction vulnerability under distribution shift. Using COVID-19 as a case study across 11 tasks in 3 domains:
(1) Coverage drops range from negligible ($<$1\%) to catastrophic ($>$70\%) under identical shift, all statistically significant ($p \leq 0.005$);
(2) SHAP concentration correlates with which multiclass tasks fail ($\rho=0.833$ within supply chain, $\rho=0.691$ across 3 domains);
(3) we provide mechanistic intuition via conformity score stochastic dominance, verified empirically (KS $= 0.68$--$0.96$ for catastrophic tasks);
(4) binary APS is structurally protected against this failure mode regardless of concentration;
(5) quarterly retraining partially mitigates vulnerable coverage loss by +19~pp ($p=0.04$);
(6) ACI recovers coverage for vulnerable tasks but inflates sets to 30--82\% of classes for those needing intervention; robust tasks need no ACI.

The diagnostic is pre-deployment (validation data only), actionable (retrain/skip decision), and stable (threshold effective across 30--45\%).

More broadly, our results suggest that the \textit{structure} of learned feature importance---not just the presence of distribution shift---determines whether conformal guarantees hold in practice. This opens a direction for pre-deployment model auditing based on importance concentration analysis.

\section{Task Independence Analysis}\label{app:icc}

We analyze pseudo-replication in the 50-seed design using intraclass correlation (ICC).

\textbf{Between-task ICC.} For coverage drops, ICC $= 0.675$ (95\% CI: $[0.47, 0.90]$; $F(7,392)=104.6$), confirming that task identity explains the majority of seed-level variance. The design effect is 34.1, yielding effective $n_{\text{eff}} = 400/34.1 = 11.7$---exceeding the 8 task-level observations. For test coverages, ICC $= 0.720$ (95\% CI: $[0.52, 0.92]$). These values confirm that the $n=8$ tasks constitute meaningfully independent observations for the Spearman correlation analysis.

\textbf{Per-task ICC(val,test).} For each task, we compute ICC between the 50 validation coverages and 50 test coverages (paired by seed). All 8 per-task ICCs are negative ($-0.80$ to $-0.10$), indicating that seeds producing above-average validation coverage do \textit{not} produce above-average test coverage. This means paired Wilcoxon tests are conservative: the effective sample size for within-task paired tests \textit{exceeds} 50, so the reported $p$-values are, if anything, too large.

\textbf{Result.} RF SHAP concentration does \textit{not} correlate with RF coverage drop ($\rho = 0.30$, $p = 0.47$, $n=8$), in contrast to LightGBM ($\rho = 0.833$, $p = 0.010$). Cross-model concentration correlation is moderate ($\rho = 0.54$, $p = 0.17$).

\textbf{Interpretation.} Two factors explain the discrepancy. First, RF produces different vulnerability profiles: the three LightGBM-catastrophic tasks (71--77\% drop) show much smaller RF drops (14--50\%), because RF's bagging produces smoother probability surfaces less sensitive to individual OOD features. Second, RF concentration has a compressed range: 6 of 8 tasks cluster at 22--28\%, eliminating the separation between vulnerable and robust tasks that LightGBM exhibits (24--29\% vs.\ 43--54\%).

This confirms SHAP concentration is a \textit{model-specific} diagnostic: it measures how a particular model's learned dependence structure creates vulnerability, not a universal property of the task or data. Practitioners should compute concentration for their deployed model class.
