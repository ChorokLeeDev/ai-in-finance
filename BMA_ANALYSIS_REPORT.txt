METHODOLOGY: BAYESIAN MODEL AVERAGING FORMULA
================================================================================

BMA uses the posterior model probability:

  P(M_k | data) ∝ P(data | M_k) * P(M_k)

For nested models with equal priors, BIC approximation gives:

  w_k = exp(-0.5 * BIC_k) / Σ_j exp(-0.5 * BIC_j)

  BIC_k = -2 ln(L_k) + p_k * ln(N)

  where L_k = max likelihood, p_k = # parameters, N = # observations

Posterior Inference:

  θ̂_BMA = Σ_k w_k * θ̂_k  (weighted average of parameter estimates)

For p-values:

  p_BMA = Σ_k w_k * p_k   (weighted average of test statistics)

Uncertainty Quantification:

  95% CI via bootstrap from posterior predictive distribution:
  - Sample cluster index from categorical(w_1,...,w_K)
  - Sample statistic from that cluster's distribution
  - Repeat 10,000 times and compute percentiles

  - Random initialization strategy: k-means clustering (k=3)
  - EM convergence tolerance: 1e-4
  - Maximum EM iterations: 100
  - Outcome: 7 distinct local optima clusters

Frozen OOS Validation:
  - Training period: 1990-2012 (5,744 days)
  - Test period: 2013-2024 (2,814 days)
  - Procedure: Train HMM on 1990-2012, apply to 2013-2024
  - Regime relabeling: Based on training-period data norm (no lookahead)
  - Granger lag: Fixed at lag=1 (BIC-optimal from in-sample analysis)

Granger Causality Test:
  - Null: y_t = Σ_i α_i y_{t-i} + ε_t
  - Alternative: y_t = Σ_i α_i y_{t-i} + Σ_i β_i x_{t-i} + ε_t
  - Test: F-test for joint significance of {β_i}
  - HAC correction: Standard F-distribution (Newey-West inflation negligible at lag=1)
  - y = SMB (size premium), x = HML (value premium)

BMA Implementation:
  - Model weights: BIC-based posterior probabilities
  - Point estimate: Cluster-weighted average of Granger p-values
  - Uncertainty: Bootstrap from posterior predictive (10,000 replicates)
  - Confidence intervals: 2.5th and 97.5th percentiles of bootstrap distribution
